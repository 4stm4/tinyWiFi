## v0.2.0 — 2026-07-27

Большой набор функций поверх MVP: VPN, расписание интернета, AdBlock, Радар,
WAN, DNS, авторизация и HTTPS, e-paper дисплей, локализация.

### Добавлено
- **VPN (AmneziaWG / WireGuard).** Импорт `vpn://` и `.conf`, управление
  туннелями напрямую (без `awg-quick`), роутинг трафика и список bypass-IP,
  автостарт туннеля между перезагрузками, удаление туннелей из UI.
- **Расписание интернета.** Понедельное окно доступа с ночным режимом
  (через полночь), enforcement через отдельную nft-цепочку `schedule`,
  ручная блокировка/разблокировка «сейчас», страница «График».
- **AdBlock.** Аналог pi-hole через `nanodns block_file`, автоскачивание
  списка при первом включении, кастомные правила.
- **Радар.** Страница пассивного Wi-Fi-сканирования через switch-адаптер.
- **WAN.** Страница и API управления WAN-интерфейсом, поддержка PPP-модема
  (`ppp0`).
- **DNS.** Интеграция `nanodns` (core-модуль, API, UI), поле `router_name`.
- **DHCP.** Статические аренды (`static=name,mac,ip`).
- **Клиенты.** MAC ACL (whitelist/blacklist) со страницы аренд, трафик Wi-Fi
  на дашборде с авто-обновлением.
- **Безопасность.** Авторизация UI через argon2id + сессии, rate-limiting и
  защита от brute-force, `/health` для мониторинга, HTTPS/TLS с
  самоподписанным сертификатом и редиректом с HTTP, случайный пароль на
  первом запуске вместо `admin`.
- **Локализация.** Переключатель EN/RU в веб-интерфейсе.
- **Дисплей.** E-paper Waveshare 2.13" через `spidev` + `embedded-graphics`,
  круговые графики RAM/CPU, иконки clients/WAN/uptime, smart-refresh.
- **Система.** Версия, хост, ядро и статус NTP на странице «Система»,
  структурные логи через `tracing`.

### Исправлено (ревью 2026-07-27)
- **Расписание: ручная блокировка жила ≤60 c.** Кнопки «Выключить/Включить
  сейчас» откатывались минутным `apply_schedule`. Введён маркер-оверрайд
  (`/tmp/tinywifi_schedule_override`), который держится до границы окна,
  сохранения расписания или перезагрузки.
- **Расписание: fail-open при неизвестном времени.** При сбое `date`
  функция возвращала «Пн 00:00» и могла ложно заблокировать интернет;
  теперь при неопределённом времени блокировка не ставится.
- **Расписание: валидация `HH:MM` в API** — кривое время (`25:99`) отвергается
  с 400; починен латентный баг с пустыми строками в `DayWindow::default()`.
- **Расписание: громкая ошибка при отсутствии nft-цепочки `schedule`** на
  старте вместо тихого сбоя раз в минуту.
- **VPN: `set_autostart(None)` больше не глотает ошибки записи** (игнорируется
  только `NotFound`), ошибка пробрасывается в `delete_tunnel`.
- **Web: autostart-туннель поднимается вне async-рантайма** (`spawn_blocking`),
  чтобы недоступный endpoint не задерживал старт панели.

### Изменено
- `hostapd`: `noscan=1`, `dtim_period=1`, `beacon_int=100`, `ieee80211w=1`;
  убран PMKSA-кэш и `WPA-PSK-SHA256` из `wpa_key_mgmt` (чинит reconnect-loop).
- `nftables`: цепочка `schedule` и jump из `forward` для LAN-подсети.
- `Mutex → parking_lot`, чтобы паника не отравляла лок навсегда.
- `argon2`: параметры снижены под embedded (64 МБ → 8 МБ).

## v0.1.0 — 2026-06-01

Первый релиз TinyWifi MVP.

### Ядро (`tinywifi-core`)
- Проверки доступности файлов, сервисов и сетевых интерфейсов перед любыми
  действиями (правило «проверь до того как трогать»).
- Парсер `hostapd.conf` (line-preserving, round-trip комментариев и
  неизвестных директив) и редактирование Wi-Fi с валидацией.
- Парсер `nanodhcp.conf` в реальном формате `key=value` с сохранением
  неизвестных ключей при записи.
- Чтение лизов, метрики хоста (`/proc`), модель системного статуса.
- Безопасные правки: backup → запись → перезапуск → проверка → откат;
  верификация запуска с ретраями; примитив `AutoRevert` (commit-confirm).
- Кросс-платформенный сервис-слой: systemd / SysV-init (`/etc/init.d`) /
  процессы.

### Веб-панель (`tinywifi-web`)
- Дашборд с живыми данными, страница System (статусы, рестарт, reboot).
- REST API: status, wifi, dhcp, leases, services, reboot.
- Commit-confirm с автооткатом (`?hold=` + `/confirm`).
- 10 интеграционных тестов HTTP-слоя.

### Дисплей (`tinywifi-display`)
- Демон статуса с абстракцией рендера (`Renderer`), мягкая деградация полей.

### Развёртывание
- Проверено на стенде «4stm4 netOS» (Buildroot, aarch64, busybox-init):
  реальные hostapd/nanodhcp, веб-панель на порту 80.

### Известные ограничения
- Кнопки Restart работают только для сервисов с отдельным init-скриптом; на
  netOS весь AP-стек ведёт мастер-скрипт `S10tinywifi`.
- Схема `[ap]/[network]/[dhcp]` из заготовки netOS-конфига пока не
  поддерживается (используется собственная `[web]/[paths]/[services]`).
